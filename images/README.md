# Images

The images that ship with imp: `base/` (Ubuntu with Docker), which each release publishes as
`imp-base`, and two bring-your-own examples: `examples/hello/`, one HTTP service, and
`examples/coder/`, Claude Code and gh for a coding agent. The
[images guide](../docs/guides/images.md) covers how to build them, what a guest takes from an image,
services, and how to make your own.
